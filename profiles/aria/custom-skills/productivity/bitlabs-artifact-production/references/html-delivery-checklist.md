# HTML Deliverable Preflight

Use this checklist immediately before reporting or requesting delivery approval.

## Scope and Format

- [ ] HTML is the requested or default format.
- [ ] No PDF, PPTX, DOCX, HWP, or other derivative was created merely from habit.
- [ ] If a non-HTML format was requested, the native format or an explicitly accepted substitute was produced.
- [ ] The artifact has a descriptive filename and a complete title.

## Content

- [ ] Audience, purpose, and primary action are clear above the fold or at the start.
- [ ] The information architecture transforms the source instead of mirroring it blindly.
- [ ] Assumptions are labeled, especially duration, audience, and delivery mode.
- [ ] Current or external claims have nearby citations and a source list.
- [ ] Confidential data is absent or appropriately masked.

## Static Verification

- [ ] The file exists and is non-empty.
- [ ] HTML parses without fatal structural errors.
- [ ] `<html lang="ko">` or the correct language is set.
- [ ] `<title>` and viewport metadata exist.
- [ ] IDs are unique.
- [ ] Every local `#anchor` target exists.
- [ ] Heading order is coherent.
- [ ] Embedded JavaScript passes a syntax check when a runtime is available.
- [ ] Expected sections, tables, exercises, code blocks, or controls are counted programmatically.
- [ ] External dependencies are absent or necessary, pinned, and documented.

## Experience and Print

- [ ] Primary desktop and mobile layouts are responsive.
- [ ] Controls are keyboard-usable and have clear labels.
- [ ] `prefers-reduced-motion` is respected when motion exists.
- [ ] Document-like artifacts include useful `@media print` rules.
- [ ] A browser screenshot or rendered inspection was performed when tooling permits.
- [ ] If no rendering was possible, the report says “static verification only” rather than claiming visual verification.

## Delivery Gate

- [ ] Recipient, purpose/subject, complete message body, attachment, links, and impact are shown together.
- [ ] Required approval is explicit and applies to the exact payload.
- [ ] Approved payload was not changed afterward.
- [ ] The external system returned the intended target and a message/file identifier.
- [ ] The target was read back when the platform supports it; otherwise the readback limitation is stated.
